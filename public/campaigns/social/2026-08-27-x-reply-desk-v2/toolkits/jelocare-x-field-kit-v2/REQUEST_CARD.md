# Request card

You can write naturally or fill only the lines you know:

```text
Goal: next reply | reply | follow-ups | Zapshot | article | spotlight |
      repurpose | measure | audit | post
Source URL:
JeloCare reply URL:
Files attached:
Channel: X | WhatsApp | Instagram
Media rights: owned | licensed | platform-native-only | unknown
Authorized media scope/channels, if documented:
What I want this to achieve:
```

For a reply, a URL is enough only when the host has live browsing. Otherwise
attach a complete screenshot. For a Zapshot, attach the complete native thread
screenshot and matching original video file. Both identities and all prose must
be visible. A media thumbnail or different MP4 is not enough. The AI selects
crop regions, runs the preview, and performs the visual review; you do not need
to supply coordinates or a recipe. If the source is incomplete or obstructed,
the AI should name the precise replacement needed.

Source/reply URLs support live verification when browsing is available. When
only supplied evidence is available, private rendering may proceed while live
state stays `not-live-verified`. Unknown rights remain local/private. For
publication, approve the exact target/copy/media unit in that live conversation.
